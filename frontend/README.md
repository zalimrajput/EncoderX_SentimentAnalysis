# Frontend — EncoderX Sentiment Analysis

Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS 4 dashboard for
the EncoderX sentiment analysis project.

See the **[root README](../README.md)** for full setup instructions, the API
reference, and model details.

```bash
npm install
npm run dev     # → http://localhost:3000
```

The FastAPI backend must be running on `http://localhost:8000` (override with
`NEXT_PUBLIC_API_URL`).
